# terraform-azure-network
# Terraform Azure Network Project

This project demonstrates how to deploy basic Azure networking resources using Terraform.

## Resources Created

- Azure Resource Group
- Azure Virtual Network
- Azure Subnet
- Network Security Group
- NSG Security Rule for SSH

## Technologies

- Microsoft Azure
- Terraform
- Azure Resource Manager
- Azure CLI
- Git
- GitHub
